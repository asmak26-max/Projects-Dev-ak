# Result Analyzer

## 📌 About

**Result Analyzer** is a Java-based automation tool that helps teachers **fetch and analyze MSBTE student results automatically**.

## ❓ Problem

Teachers normally:

* Enter enrollment numbers one by one.
* Solve CAPTCHAs.
* Collect and analyze results manually.

This takes time and can cause errors.

## 💡 Solution

The system:

1. Takes an **Excel file containing enrollment numbers**.
2. Automatically fetches student results from the **MSBTE website** using Selenium.
3. Processes the result data.
4. Converts the data into an **Excel file**.
5. Provides the analyzed file for download.

## 🛠️ Technologies

* **Java / Spring Boot**
* **Selenium** – web automation
* **JSP & JavaScript** – web interface
* **Apache POI** – Excel processing

## 🎯 Benefits

* Saves teachers' time
* Reduces manual work
* Minimizes human errors
* Makes result analysis faster and easier
